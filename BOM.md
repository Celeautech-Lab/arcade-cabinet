# Bill of Materials (BOM)

## 1. Electronics

| Item | Quantity | Specifications / notes |
|---|---:|---|
| Single-board computer | 1 | Raspberry Pi 4 Model B or equivalent; use the board specified by the software image. |
| MicroSD card | 1 | 32 GB or larger; suitable for the selected operating-system image. |
| 5 V power supply | 1 | Regulated supply sized for the computer and USB peripherals. |
| LCD display | 1 | HDMI-compatible display sized for the screen opening. |
| HDMI cable | 1 | Length suitable for the cabinet layout. |
| Arcade joystick | 1 | Standard microswitch arcade joystick. |
| Arcade push buttons | 8 | Match the control-panel openings and the selected input wiring. **Button warning:** verify the button diameter, microswitch clearance, terminal orientation, and wiring before cutting or ordering; button layouts and connector types are not interchangeable. |
| USB encoder / controller board | 1 | Arcade-control encoder compatible with the computer and selected joystick/buttons. |
| Stereo speakers | 2 | Cabinet speakers matched to the amplifier output and available mounting space. |
| Stereo amplifier | 1 | Compact amplifier matched to the speaker impedance and supply voltage; check its actual dimensions before fabricating the mounting bracket. |
| Volume control / potentiometer | 1 | Compatible with the selected amplifier; fit the control-panel opening. |
| Wiring harness and connectors | 1 set | Power, display, controls, and audio wiring; follow [the wiring diagram](Media/wiring_diagram.png). |
